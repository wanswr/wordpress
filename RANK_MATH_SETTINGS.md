# Текущая конфигурация Rank Math (Аудит)

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **pt_page_title** | `%title% %sep% %sitename%` | ✅ Шаблон заголовка страниц (Исправлено) |
| **pt_page_description** | `%excerpt%` | Шаблон описания страниц |
| **homepage_title** | `%sitename% %page% %sep% %sitedesc%` | Заголовок главной страницы |
| **knowledgegraph_type** | `company` | Тип организации для Google Knowledge Graph |
| **local_business_type** | `Organization` | Тип бизнеса для локального SEO |
| **items_per_page (Sitemap)** | `200` | Лимит ссылок в одной карте сайта |
| **html_sitemap** | `on` | Генерация HTML-карты сайта |
| **tax_category_sitemap** | `off` | Индексация категорий (отключена) |
| **pt_post_default_rich_snippet** | `article` | Тип разметки по умолчанию для постов |
| **pt_page_default_rich_snippet** | `article` | Тип разметки по умолчанию для страниц |

---
**Примечание:** Значение `pt_page_title` было изменено в ходе последних работ по исправлению критической ошибки шаблона заголовков.
